# 🚧 RoadGuard AI

### AI-Powered Road Safety Application

**Developed by Manoj | GECoders**

RoadGuard AI is an AI-powered mobile application designed to improve road safety by detecting potholes and road cracks using computer vision. It captures GPS coordinates of detected road hazards and displays them on a map.

## 🚀 Project Goals

* Detect potholes and road cracks using AI.
* Capture and display hazard locations using GPS.
* Visualize road hazards on OpenStreetMap.
* Support safer roads through technology.

## 🛠️ Built With

* Flutter
* Python / YOLO / TensorFlow Lite
* GPS Location Services
* OpenStreetMap
